## Pipeline (what produced the score)

```
competition CSVs
    → 75 row-wise features (BEST_0.40929.py)
    → 100 LightGBM models, PAY-types only          → artifacts/test_pay_types.csv
    → 100 LightGBM models + nested PAY target encoding
                                                   → artifacts/submission_push4_te.csv
    → 50/50 average of those two test vectors
    → clip to (1e-6, 1-1e-6)
    → submission_blend_te_paytypes.csv
```

No other post-processing. No hand-edited probabilities.

## Execution order

Python 3.13 (recorded run: 3.13.14).

```text
pip install -r requirements.txt
python reconstruct_submission.py          # instant check: upload == 50/50 of saved parts
python BEST_0.40929.py                    # optional: retrain the PAY-types half (~minutes)
python train_te_and_blend.py              # optional: retrain TE + blend (~25–30 min)
```

1. `reconstruct_submission.py` proves the uploaded CSV is exactly `0.5 * PAY-types + 0.5 * TE` from `artifacts/`. This is the verification path.
2. `BEST_0.40929.py` retrains the 100-model PAY-types parent (writes `outputs/submission_lgbm_pay_types_0.40929.csv`).
3. `train_te_and_blend.py` retrains the 100-model nested-TE half, then blends with the **saved** PAY-types artefacts in `artifacts/` at weight 0.5. Writes `outputs/` — do **not** replace the root CSV with a re-run unless you label it as regenerated.

## Random seeds and settings

- Global seed: `42` (`PYTHONHASHSEED`, `random`, `numpy`)
- Fold/repeat seeds: `1000 + r` for `r` in `0..9` (also `bagging_seed`, `feature_fraction_seed`, `data_random_seed`)
- `StratifiedKFold(n_splits=10, shuffle=True, random_state=seed)`
- Nested TE inner folds: `StratifiedKFold(n_splits=5, shuffle=True, random_state=seed)`
- LightGBM: `objective=binary`, `metric=binary_logloss`, `learning_rate=0.1`, `num_leaves=31`, `deterministic=True`, `force_row_wise=True`
- `num_boost_round=2000`, early stopping `100` rounds on the scored fold
- TE smoothing `M=50`
- Ensemble: 100 PAY-types models + 100 TE models, then **unweighted 50/50** of the two averaged probability vectors
- Probabilities clipped to `[1e-6, 1-1e-6]`

## Which script generates the prediction file

The uploaded file was generated by `train_te_and_blend.py` (then named `run_te_and_blend.py` in the working tree) after `BEST_0.40929.py` had already produced the PAY-types test vector. `reconstruct_submission.py` rebuilds that last mix from saved artefacts without training.
